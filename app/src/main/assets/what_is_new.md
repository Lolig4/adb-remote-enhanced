### What's new

#### v1.1.0 (26/2/2025)

- added [Files](http://adbremote.netlify.app/guide/how-to-use-files) feature to exchange files with the connected device
- added [Clipboard](http://adbremote.netlify.app/guide/how-to-use-clipboard) feature
- added [NTP](http://adbremote.netlify.app/guide/how-to-use-ntp) feature
- [Wireless debuging mode](https://adbremote.netlify.app/guide/wifi-pairing-mode) is now stable. You can connect not only Android TVs and boxes but also **phones and tablets**.
- added [per-app language](https://support.google.com/android/answer/12395118) support for Android 13 and above
- added support for icon packs
- added multiple customizable icon shapes
- cached installed app list for faster loading
- added a long-press feature to force stop apps
- added 3 button control modes to support legacy devices
- Apps in Search now shows all openable apps by default. This setting can be changed in the app settings.
- UI enhancements & overall performance improvements
